Python, JAX, Flax

Mixture-of-Experts Layer for Named Entity Recognition

Python, PyTorch, HuggingFace

  • Built a Mixture-of-Experts layer from scratch (4 expert MLPs, top-2 gating, load-balancing loss) and added it to a BiLSTM tagger with GloVe, character-CNN and casing features.
  • Tested on CoNLL-2003 over 3 seeds against a plain BiLSTM and a parameter-matched dense-FFN control. The balanced MoE matched the baseline (89.3 ± 0.4 vs 89.4 ± 0.3 entity-F1) and beat the unbalanced MoE by about 0.9 F1, with expert usage spread evenly (17–33% per expert).

Instruction-Tuned LLaMA for Domain-Specific QA

Python, PyTorch, HuggingFace, PEFT, bitsandbytes

  • Built a QLoRA instruction-tuning pipeline for LLaMA-family models (7–8B): a 4-bit NF4 base with LoRA adapters on the attention projections, sized to train on a single 16–24 GB GPU.
  • Masked the loss to response tokens only, so the model learns to answer rather than echo the prompt, and kept the prompt template in one file so training and inference can't drift apart.
  • Held out a validation split and kept the best checkpoint by eval loss to catch overfitting on small datasets, with scripts to merge the adapter and compare the fine-tuned model against the zero-shot base on the same prompts.
