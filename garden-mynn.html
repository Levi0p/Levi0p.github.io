Training Data and a Linear Classifier

Examples of truth used to teach a predictor / classifier are called the training data.

Say we are given two examples, x = 3, y = 1 (a caterpillar) and x = 1, y = 3 (a ladybug), and we have to establish a classifier that separates them.

Use a linear model, y = Ax. Pick some random A value, look at the error, i.e. (true value − expected value), and adjust A accordingly. But what is the best way to adjust? The error is E = (A + ΔA)x − Ax, so E = ΔAx and therefore:

ΔA = E / x

So we make a random guess for A and then set ΔA = E/x, for the current x and the error we get, and our new function y = (A + ΔA)x is accurate for that example. But if we keep doing this for every new example, our classifier will simply match the last training example, so we might as well not have bothered with the earlier training examples. To fix this we moderate the updates. The moderating factor is called the learning rate, L:

ΔA = L · (E / x)

So if L = 0.5 we only update half as much as we would have done without moderation.

Training examples from the real world can be noisy or contain errors, so moderating updates also helpfully limits the impact of these false examples.

The XOR Problem

There is a problem with a simple linear classifier: it can't learn XOR. OR and AND each work with a single dividing line, XOR does not.

How to fix this? Easy, we use multiple linear classifiers. XOR needs two lines.

Backpropagation: Splitting the Error

Previously it was very simple to refine a simple linear classifier, as it only had one node. But what if there are more than one? What we do is split the error with respect to the weights: the more the weight, the more it contributes towards the error.

We use weights to propagate signals forward and to propagate the error backwards from the output back through the network. This is why it is called backpropagation.

Neural networks learn by refining their link weights. This is guided by the error, i.e. the difference between the right answer given by the training data and their actual output.

ehidden,1 = W1,1W1,1 + W1,2 × eoutput,1 + W1,2W1,1 + W1,2 × eoutput,2

And we work backwards to find the rest of the errors.

Gradient Descent and the Error Function

Gradient descent: after you have taken a step, you look again at the surrounding area to see which direction takes you closer to your objective, and then you step again in that direction. You keep doing this until you're happy you've arrived at the bottom.

Now we need to find an error function. The simplest one can be (target − actual), but there is a problem with that:

node 1 → e1 = 0.1
node 2 → e2 = −0.1
total error = e1 + e2 = 0

It shows no error even though there is an error.

So our next option is |target − actual| or (target − actual)². We don't use |target − actual| as |x| is discontinuous around the minimum point, so to avoid that we use (target − actual)². The x² function is smooth and always continuous.

The Derivative of the Error

∂E/∂Wj,k → how the error E changes as the weight Wj,k changes.

E = Σn (tn − on)²

where on is the output at node n and tn is a constant, the target value.

But the error function doesn't need to sum over all the output nodes, so with E = (tk − ok)²:

∂E∂Wj,k = ∂∂Wj,k (tk − ok)²

Now, by the chain rule:

∂E∂Wj,k = ∂E∂ok × ∂ok∂Wj,k = −2(tk − ok) × ∂ok∂Wj,k

ok is the output of node k, which is the sigmoid applied to the weighted sum of the connected incoming signals, so:

∂E∂Wj,k = −2(tk − ok) × ∂∂Wj,k sigmoid(Σj Wj,k · oj)

The derivative of the sigmoid is:

∂∂x sigmoid(x) = sigmoid(x) · [1 − sigmoid(x)]
∂E∂Wj,k = −2(tk − ok) × sigmoid(Σj Wj,k · oj) · [1 − sigmoid(Σj Wj,k · oj)] · oj

We can forget about the 2 as it won't change much, so:

∂E∂Wj,k = −(tk − ok) · sigmoid(Σj Wj,k · oj) · [1 − sigmoid(Σj Wj,k · oj)] · oj

or, writing the error as ej:

∂E∂Wi,j = −ej · sigmoid(Σi Wi,j · oi) · [1 − sigmoid(Σi Wi,j · oi)] · oi

Thus:

new Wj,k = old Wj,k − α · ∂E∂Wj,k

α is the learning rate. It moderates the strength of these changes to make sure we don't overshoot.

ΔWj,k = α · Ek · sigmoid(Ok) · [1 − sigmoid(Ok)] · OjT

Saturation

A neural network can be saturated if the inputs are very large, as the sigmoid becomes flat for large values, so the gradient almost vanishes. And if oj is too small, we can lose accuracy.

Why Activation Functions, and ReLU

If we had no activation function at all, then the whole network would just collapse into a single linear transformation no matter how many layers there are. So the network could only model linear functions, not complex non-linear data.

ReLU is the rectified linear unit activation function, where:

ReLU(x) = x, x ≥ 0
ReLU(x) = 0, x < 0

This non-linearity is enough for networks to learn complex patterns. It is preferred over sigmoid when you want fast training and good gradient flow.

Cross-Entropy

Cross-entropy measures how wrong the predicted probabilities are. It takes the −log(probability for the true class). Lower loss means higher confidence in the correct class.
