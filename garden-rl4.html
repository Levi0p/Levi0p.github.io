Can We Drop the Policy Gradient

Aπ(st, at) says how much better at is than the average action under π, so argmaxat Aπ(st, at) is the best action from st if we then follow π, and that action is at least as good as anything π would have picked regardless of what π is, so forget policies and just do this

π′(at | st) = 1 if at = argmaxat Aπ(st, at) and 0 otherwise

π′ is at least as good as π and probably better, and doing this over and over is policy iteration

1. evaluate Aπ(s, a)
2. set π ← π′

and since Aπ(s, a) = r(s, a) + γE[Vπ(s′)] − Vπ(s) the hard part is again just evaluating Vπ(s)

Dynamic Programming

Lets assume for now that we know p(s′ | s, a) and that s and a are both discrete and small, like a 4 by 4 grid with 16 states and 4 actions per state, then we can store all of Vπ(s) in a table and T is a 16 × 16 × 4 tensor

The bootstrapped update just uses the current estimate on the right side

Vπ(s) ← Ea ~ π(a | s) [ r(s, a) + γ Es′ ~ p(s′ | s, a) [Vπ(s′)] ]

and since our π′ is deterministic π(s) = a it simplifies to Vπ(s) ← r(s, π(s)) + γEs′ ~ p(s′ | s, π(s))[Vπ(s′)]

Even simpler, argmaxa Aπ(s, a) is the same as argmaxa Qπ(s, a) coz V(s) doesnt depend on a, and Qπ(s, a) = r(s, a) + γE[Vπ(s′)] is a bit simpler to compute, so if we think of Q as a table with one row per state taking the max of each row gives us the new policy and also approximates the new value, so we skip the policy and compute values directly and that is value iteration

1. set Q(s, a) ← r(s, a) + γE[V(s′)]
2. set V(s) ← maxa Q(s, a)

Fitted Value Iteration

Now this works but we cant have a table coz it gets way too big, an image based game with 200 × 200 pixels at 2553 colours each has more states than there are atoms in the universe, that is the curse of dimensionality, so we approximate the value function with a neural net Vφ : S → ℝ and regress it onto the target

1. set yi ← maxai ( r(si, ai) + γE[Vφ(s′i)] )
2. set φ ← argminφ ½ Σi || Vφ(si) − yi ||2

The catch is step 1, to take a max over actions you need to know what would happen for each different action from the same state which means you need the transition dynamics

When We Dont Know the Dynamics: Fitted Q Iteration

So go back to policy iteration but evaluate Q instead of V

Qπ(s, a) ← r(s, a) + γ Es′ ~ p(s′ | s, a) [ Qπ(s′, π(s′)) ]

We are updating Q instead of V coz if we just deal with Q we dont need to know the transition probs at all, the expectation over s′ can be fit using samples and all we need is (s, a, s′) and the reward and thats it which is really useful, and doing the same max trick as before gives fitted Q iteration

1. collect a dataset {(si, ai, s′i, ri)} using some policy
2. set yi ← r(si, ai) + γ maxa′i Qφ(s′i, a′i)
3. set φ ← argminφ ½ Σi || Qφ(si, ai) − yi ||2 and repeat steps 2 and 3 K times

Here maxa′ Qφ(s′, a′) approximates E[V(s′)] and it doesnt need any simulation of different actions, you just plug every action into the network, the knobs are the dataset size N and the collection policy, the number of iterations K and the gradient steps S inside each fit, and this whole thing is off policy coz the max doesnt care which policy collected the data

Online Q Learning and Exploration

If you take K = 1 and one gradient step per sample you get online Q learning

1. take some action ai and observe (si, ai, s′i, ri)
2. yi = r(si, ai) + γ maxa′ Qφ(s′i, a′)
3. φ ← φ − α (dQφ/dφ)(si, ai) (Qφ(si, ai) − yi)

The final policy is just the argmax of Q but using it in step 1 to collect data is a bad idea coz if Q is wrong early on the greedy policy keeps taking the same few actions and never finds out anything better, so we need exploration

Epsilon greedy takes the argmax action with probability 1 − ε and a random other action otherwise, and Boltzmann exploration samples actions with π(at | st) ∝ exp(Qφ(st, at)) so actions that are almost as good get tried more often than ones that are clearly bad

Does Any of This Converge

For tabular value iteration define an operator B where BV = maxa ra + γTaV, the optimal V* is a fixed point of B ie V* = BV* and it always exists, is always unique and always matches the optimal policy, and B is a contraction in the ∞ norm ||BV − BV̄||∞ ≤ γ||V − V̄||∞ so every step gets us closer and tabular value iteration converges

Fitted value iteration is really V ← ΠBV where Π is the projection onto whatever the neural net can represent ie the least squares fit, Π is a contraction in the ℓ2 norm and B is a contraction in the ∞ norm but ΠB together is not a contraction of any kind, so fitted value iteration does not converge in general and often not in practice either, and the same goes for fitted Q iteration and online Q learning

But isnt step 3 of online Q learning just gradient descent which converges right, no coz Q learning is not gradient descent, the target yi depends on φ too and we dont take a gradient through it, so it has a moving target which makes it hard for it to ever converge

And a sad corollary, the critic in actor critic is doing the exact same kind of fitted bootstrapped evaluation (just without the max) so it doesnt converge in theory either, quick terminology note here Vπ is the value of policy π which is what the critic learns and V* is the value of the optimal policy which is what Q learning goes after

Correlated Samples and Replay Buffers

Online Q learning has two more problems, sequential states are strongly correlated so the network overfits to whatever part of the world it is in right now, and the target value keeps changing, one fix for the correlation is parallel workers like in actor critic and the other much more common fix is a replay buffer

So basically fitted Q iteration is the whole recipe for learning from a fixed offline dataset you already collected, while a replay buffer is just the dynamic memory box that online algos like DQN use to store recent transitions and pick random mini batches from on the fly, sampling randomly from the buffer breaks the correlation and since Q learning is off policy it doesnt matter that the data came from older policies

1. collect dataset {(si, ai, s′i, ri)} using some policy and add it to B
2. sample a batch (si, ai, s′i, ri) from B
3. φ ← φ − α Σi (dQφ/dφ)(si, ai) (Qφ(si, ai) − [r(si, ai) + γ maxa′ Qφ(s′i, a′)]) and repeat 2 and 3 K times

K = 1 is common though a larger K is more efficient, and you keep collecting with your latest policy like epsilon greedy so the buffer keeps growing with relevant data

Target Networks and DQN

The moving target is still there so we want a mix of fitted Q iteration and the replay buffer, we save a copy of the params φ′ ← φ and compute targets with that frozen copy so the targets dont change in the inner loop and each inner loop becomes plain supervised regression

1. save target network params φ′ ← φ
2. collect dataset {(si, ai, s′i, ri)} using some policy and add it to B
3. sample a batch from B
4. φ ← φ − α Σi (dQφ/dφ)(si, ai) (Qφ(si, ai) − [r(si, ai) + γ maxa′ Qφ′(s′i, a′)])

The classic DQN from Mnih et al is just this with K = 1, take one action and add it to the buffer, sample a mini batch uniformly, compute yj = rj + γ maxa′j Qφ′(s′j, a′j) using the target network, take a gradient step and copy φ into φ′ every N steps, a smoother option is Polyak averaging φ′ ← τφ′ + (1 − τ)φ every step with τ like 0.999 so the target lags behind by the same amount all the time

Overestimation and Double Q Learning

Q learning tends to overestimate values and the reason is that E[max(X1, X2)] ≥ max(E[X1], E[X2]), our Q values are noisy and taking a max over noisy numbers picks whichever one got lucky noise so the target is biased upwards

Look at maxa′ Qφ′(s′, a′) = Qφ′(s′, argmaxa′ Qφ′(s′, a′)), the action is selected by Qφ′ and the value also comes from Qφ′ so the same noise gets used twice, if the noise in those two were decorrelated the problem goes away, so dont use the same network to choose the action and to evaluate it

Double Q learning uses two networks that each pick the action for the other, and in practice you dont even need a new network, just use the current network to pick the action and the target network to evaluate it

standard   y = r + γ Qφ′(s′, argmaxa′ Qφ′(s′, a′))
double   y = r + γ Qφ′(s′, argmaxa′ Qφ(s′, a′))

Multi Step Returns in Q Learning

In the target y = r + γ max Qφ′ if Qφ′ is bad then r is the only part giving real signal and if Qφ′ is good then the max part matters most, so Q learning by default is max bias and min variance, just like the actor critic case from part 3, and we can do the same n step trick

yj,t = Σt′=tt+N−1 γt′−t rj,t′ + γN maxaj,t+N Qφ′(sj,t+N, aj,t+N)

which gives less biased targets when Q is inaccurate and usually faster learning especially early on, but it is only actually correct when learning on policy coz those N real rewards came from whatever old policy was in the buffer and not the greedy one we are evaluating, the fixes are to just ignore it which often works well, or cut the trace by picking N on the fly so only on policy data is used, which works when the data is mostly on policy and the action space is small

Q Learning with Continuous Actions

The max over actions is easy when there are a few discrete actions but with continuous actions it is an optimization problem inside every single update, there are three options

Option 1 is stochastic optimization, the simple solution is maxa Q(s, a) ≈ max{Q(s, a1), …, Q(s, aN)} with the actions sampled from like a uniform distribution, it is dead simple and easy to parallelize but not very accurate, though do we even care how good the target is, for something more accurate there is the cross entropy method (CEM) which is a simple iterative stochastic optimization and works ok up to about 40 dimensions, and CMA-ES which is a much less simple version

Option 2 is to use a function class that is easy to optimize, NAF (normalized advantage functions) makes Q quadratic in the action so the max has a closed form

Qφ(s, a) = −½ (a − μφ(s))T Pφ(s) (a − μφ(s)) + Vφ(s)
argmaxa Qφ(s, a) = μφ(s)     maxa Qφ(s, a) = Vφ(s)

which changes nothing in the algorithm but makes the Q function less expressive

Option 3 is to learn an approximate maximizer, DDPG trains another network μθ(s) ≈ argmaxa Qφ(s, a) by solving θ ← argmaxθ Qφ(s, μθ(s)) with the chain rule dQφ/dθ = (da/dθ)(dQφ/da), it is called deterministic actor critic but it really is approximate Q learning

1. take some action ai and observe (si, ai, s′i, ri) and add it to B
2. sample a mini batch {sj, aj, s′j, rj} from B uniformly
3. compute yj = rj + γQφ′(s′j, μθ′(s′j)) using target nets Qφ′ and μθ′
4. φ ← φ − α Σj (dQφ/dφ)(sj, aj) (Qφ(sj, aj) − yj)
5. θ ← θ + β Σj (dμ/dθ)(sj) (dQφ/da)(sj, μ(sj))
6. update φ′ and θ′ eg with Polyak averaging

Practical Tips for Q Learning

Bellman error gradients can get huge so clip the gradients or use the Huber loss which is quadratic near zero and linear further out so big errors dont blow up the update

L(x) = x2/2 if |x| ≤ δ    and    δ|x| − δ2/2 otherwise

Double Q learning helps a lot in practice and is simple with no real downside, n step returns also help a lot but have the downsides from above, schedule exploration and learning rates from high to low and Adam helps too, and run multiple random seeds coz Q learning is very inconsistent between runs
